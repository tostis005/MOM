# MOM topic inventory

This folder is the canonical inventory of approved article topics for MOM.

## Approved topic files

- `TOPICS-001-1000.md` — approved topics 1–1000.
- `TOPICS-1001-2000.md` — approved topics 1001–2000, revised to reduce duplication and search-intent cannibalization against the first batch and within the batch itself.

## Mandatory use

Before drafting, rewriting, validating or proposing a topic:

1. Review all topic files in this folder, not only the current range.
2. Preserve the exact `article_number` and approved core search intent.
3. Spanish and English versions share the same `article_number` and `translation_group`; each language should be written natively for its target market.
4. Do not create a new URL when an existing topic would answer essentially the same search intent. Prefer one stronger article over several near-duplicates.
5. Keep MOM's editorial scope non-diagnostic and non-treatment-focused. Mental-health-adjacent topics may cover lived experience, stigma reduction, communication and seeking appropriate support, but should not attempt clinical diagnosis or treatment.

Article body JSON files should remain separate from this topic inventory under the article-content structure.
